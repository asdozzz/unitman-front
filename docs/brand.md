# Бренд Unitman

Знак — изометрический контейнер: белый куб на синей плитке, оранжевая верхняя грань, синие
швы. Метафора: юнит как контейнер, который собирает и поднимает Runner.

## Палитра

| Роль | HEX | Где используется |
| --- | --- | --- |
| Фон плитки | `#2f6fb0` | плитка знака, `theme-color`, `--app-primary` |
| Куб | `#ffffff` | грани |
| Верхняя грань | `#e89a2b` | единственный цветовой акцент |
| Швы | `#2f6fb0` | внутренние рёбра, совпадают с фоном плитки |
| Тёмная тема | `#11151a` | `theme-color` в тёмной схеме, фон PWA |

## Геометрия

Сетка `64×64`, плитка `rx=14`, куб внутри отступа `8`.

```
шестиугольник: 32,7 55,19.5 55,44.5 32,57 9,44.5 9,19.5
верхняя грань: 32,7 55,19.5 32,32 9,19.5
швы:           M32 32 L9 19.5, M32 32 L55 19.5, M32 32 L32 57
толщина швов:  2.5
```

Правила:

- Не менять пропорции и углы изометрии.
- Не добавлять тени, градиенты, обводки и блики.
- Не перекрашивать верхнюю грань в другой цвет, кроме `mono`-версии.
- Не уменьшать знак ниже `16px`.

## Файлы

| Файл | Назначение |
| --- | --- |
| [`public/favicon.svg`](../public/favicon.svg) | мастер и favicon для современных браузеров |
| `public/favicon.ico` | 16/32/48 для legacy и закладок |
| `public/apple-touch-icon.png` | 180×180, квадратная плитка |
| `public/icon-192.png`, `public/icon-512.png` | PWA |
| `public/icon-maskable-512.png` | Android maskable |
| `public/safari-pinned-tab.svg` | одноцветный силуэт для Safari |

Все растровые ассеты генерируются из мастера:

```bash
yarn gen:icons
```

Скрипт использует Chromium из Playwright. Если bundled-браузер не запускается (например, нет
`libasound.so.2`), укажите свой:

```bash
UNITMAN_CHROME=/path/to/chrome yarn gen:icons
```

## Компонент

```vue
import { UnitmanLogo } from "@/components/ui";

<UnitmanLogo :size="16" />
<UnitmanLogo :size="32" variant="mono" title="Unitman" />
```

- `size` — сторона в пикселях, по умолчанию `16`.
- `variant="color"` — плитка и оранжевая грань; `variant="mono"` — сплошной силуэт через
  `currentColor`, без плитки.
- `title` делает знак информативным для скринридеров; без него знак декоративный.

## Лок-ап

В хедере знак `16px` + `Unitman` `16px`/`600`, зазор `8px`. На узких экранах текст скрывается,
знак остаётся. Слово `Unitman` всегда с заглавной `U`; строчное `unitman` — только в крупных
маркетинговых материалах.
