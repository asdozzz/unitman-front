# Контекст проекта (Vue 3 + TypeScript + Yarn)

## Навигация и структура
- Весь исходный код находится в `src/`.
- **Строго запрещено** читать, искать или индексировать `node_modules/`, `.yarn/`, `.pnp.*`, `yarn.lock`, `dist/`, `coverage/` и кэш сборки (`*.tsbuildinfo`, `.vite/`).
- Для проверки установленных зависимостей и доступных скриптов читай только `package.json`.

## Менеджер пакетов и команды (Yarn)
- В проекте используется **Yarn**. Никогда не используй `npm` или `npx` и не создавай `package-lock.json`.
- Для запуска скриптов и утилит используй `yarn <script>` (например, `yarn type-check`, `yarn lint`, `yarn test`).
- Для установки новых пакетов используй `yarn add <package>` (или `yarn add -D <package>`).

## Правила разработки (Vue + TS)
- Используй **Vue 3 Composition API** с синтаксисом `<script setup lang="ts">`.
- Избегай типа `any`. Явно типизируй `props`, `emits`, сторы Pinia и ответы API.
- Не редактируй вручную автогенерируемые файлы типов (`auto-imports.d.ts`, `components.d.ts`).

# Правила UI и дизайн-системы (GitHub Primer поверх Quasar)

## Базовая архитектура
- **Стек:** Vue 3.5 (`<script setup lang="ts">`), Quasar v2.17 (`@quasar/vite-plugin`), SCSS (`sass`), TypeScript.
- **Визуальный стиль:** Строго придерживайся дизайн-системы **GitHub Primer** (плоские поверхности, высокая плотность информации, четкие границы `1px solid`, деликатные состояния наведения, скругление `6px`, системный стек шрифтов).
- **Иконки:** Используй `@primer/octicons-vue` (размер по умолчанию `16px`, выравнивание `vertical-align: text-bottom`) для всех UI-иконок вместо стандартных Material Icons.
- **Роль Quasar:** Используй Quasar исключительно как движок для логики, доступности (a11y), слотов, валидации форм, всплывающих окон и сетки. **Полностью подавляй эстетику Material Design** (никаких объемных теней elevation, кнопок в верхнем регистре `uppercase` и ripple-эффектов).
- **Иконки:** Используй официальный пакет `@primer/octicons` через компонент-обертку `GhIcon.vue` (размер по умолчанию `16px`, выравнивание `vertical-align: text-bottom`, рендер через `octicons[name].toSVG({ width: size })`) для всех UI-иконок вместо стандартных Material Icons.
## Правила работы с компонентами
1. **Никогда не используй голые UI-примитивы Quasar** (`q-btn`, `q-input`, `q-card`, `q-badge`, `q-select`, `q-tabs`, `q-dialog`, `q-table`) напрямую на страницах приложения.
2. Всегда используй существующие или создавай новые типизированные компоненты-обертки в папке `src/components/ui/` с префиксом `Gh` (например: `GhButton.vue`, `GhInput.vue`, `GhBox.vue`, `GhLabel.vue`).
3. Стилизуй компоненты через CSS-переменные, объявленные в `src/styles/primer-tokens.scss`, чтобы светлая и темная темы (`body--dark` / `[data-color-mode="dark"]`) переключались бесшовно.
4. Соблюдай компактность контролов: стандартная высота кнопок и полей ввода — `32px`, компактная (`sm`) — `28px`, крупная (`lg`) — `40px`.

## Паттерны сложных компонентов
- **Навигационные вкладки (`GhUnderlineNav.vue`):** Строятся на базе `q-tabs` с параметрами `no-caps`, `align="left"`, `indicator-color="transparent"`. У активной вкладки должна быть нижняя рамка `2px solid #fd8c73` (фирменный кораллово-оранжевый акцент Primer), полужирный текст (`font-weight: 600`) и опциональный счетчик (`GhCounter`).
- **Таблицы и списки данных (`GhTable.vue` / `GhList.vue`):** Строятся на базе `q-table` (`flat`, `bordered`, `dense`) или структурированных строк внутри `GhBox`. Фон шапки таблицы — `--bgColor-muted` (`#f6f8fa` в светлой теме / `#161b22` в темной) с текстом `12px` полужирного начертания. При наведении на строку используется `--bgColor-neutral-muted`. Чередование цветов строк (зебра) запрещено — используй только тонкие разделители `1px solid`.
- **Модальные окна (`GhDialog.vue`):** Строятся на базе `q-dialog` с карточкой со скруглением `12px` и рамкой `1px solid`. Обязательна шапка с кнопкой закрытия `X` (`GhButton variant="invisible"`), разделитель `1px`, внутренние отступы тела `16px` и футер с кнопками действий, выровненными по правому краю.
- **Выпадающие меню (`GhActionMenu.vue`):** Строятся на базе `q-menu` (`flat`, рамка `1px solid`, скругление `12px`, легкая тень `--shadow-floating-small`), внутри которого находятся пункты `q-list` со скруглением `6px` и отступами `6px 8px`.
